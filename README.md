# 星露谷 · 作物收益速算

把「这块地种什么最划算」算清楚的小工具。

## 功能

- 输入种子成本、首收天数、复收间隔、收获次数、单价，实时算出**每日净收益**
- 自动排名，前三名高亮
- 表格内单元格可直接编辑，支持增删作物、一键按收益排序
- 数据存在浏览器本地，刷新不丢

## 算法

```
占用天数 = 首收天数 + 复收间隔 × (收获次数 - 1)
日净收益 = (单价 × 收获次数 - 种子成本) ÷ 占用天数
```

## 说明

内置数值是常见作物的**参考值**，不同版本、不同技能等级、是否用品质肥料都会影响实际售价。请以你游戏内的实际数据为准，直接在表格里改。
